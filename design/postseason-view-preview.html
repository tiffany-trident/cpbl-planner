季後賽呈現 · 設計提案

季後賽期間（約 10 月）怎麼在現有網站呈現季後賽：入口放哪、篩選怎麼做、賽程卡長怎樣。

以下隊伍、比分、日期、球場皆為模擬示意，不是真實賽果

模擬依據：上半季冠軍味全（全年勝率最高 → 直接晉級台灣大賽）、下半季冠軍假設中信、外卡假設統一。賽制依現行規則：全年勝率次高的半季冠軍與外卡打四戰三勝季後挑戰賽，半季冠軍先取 1 勝並有 3 場主場（1-1-2）；台灣大賽七戰四勝。挑戰賽 10/9、台灣大賽 10/17 是媒體報導的暫定日期。

1. 入口放哪？

方案做法取捨
A 主視圖頂端專區＋賽別篩選推薦季後賽期間在 Hero 下方插入「季後賽」專區（對戰樹＋下一場）；篩選卡新增「賽別」切換（全部／例行賽／季後賽），賽程總覽照常列卡片一進站就看得到；賽程列表、購票、高鐵、天氣、收藏、打卡全部沿用。例行賽戰績仍在專區下方
B Nav 新增「季後賽」頁籤跟「新聞」「我的」一樣是獨立子頁（#playoffs）結構最乾淨，但一年只用一個月；使用者要多點一下才看到最熱門的內容
C 戰績卡加「季後賽」分頁在上半季／下半季／全年旁邊多一個分頁放對戰樹改動最小，但預設分頁不是它時容易被忽略；戰績表跟對戰樹資訊型態差很多
D 只加「賽別」篩選不做專區，季後賽只是賽程列表裡帶標籤的卡片最省工；但看不到系列戰比數、誰聽牌，季後賽最重要的資訊沒呈現

4. 篩選卡：新增「賽別」

放在「場次狀態」左邊。季後賽期間預設「季後賽」，跟例行賽結束後預設「已結束」一樣不寫入篩選記憶。選「季後賽」時月份下拉只剩 10 月，「對手」照常可用。

5. 賽程總覽的季後賽卡片

卡片結構不變，footer 標籤多「挑戰賽 G3」；可能晉級的那場加「聽牌」；必要時才打的場次加虛線「若需要」標籤（前提：官方 API 會先列出這些場次，目前未知）。

手機 375px

6. 待確認

  • 官方 API 公布賽程時，會不會先列出「必要時才打」的場次與「隊伍未定」的台灣大賽場次（影響「若需要」標籤與對戰樹的待定欄）
  • 挑戰賽「先取 1 勝」API 不會給，要由程式依賽制自己加（台灣大賽沒有）
  • 台灣大賽的主場分配（哪幾場在哪隊主場）以官方公布賽程為準，示意圖裡的球場只是假設
  • 季後賽卡片的收藏、打卡、Box 戰績頁都用 E001／C001 key（已同意的 prefix 方案）
